# Behavioral Profile (pointer)

The candidate's behavioral profile is personal and lives in `profile/behavioral.md` (template:
`profile.example/behavioral.md`). It is a self-assessment, not a validated psychometric
instrument; never present it as one.

Use it for the Behavioral Fit dimension in `04-job-evaluation.md`, for cover-letter emphasis and for
interview preparation: the "Mapping to Job Posting Language" section lists the phrases that signal
a strong fit or friction, and "Don't overstate" lists claims that must never be made.

If `profile/behavioral.md` is missing, run `/onboard`.
